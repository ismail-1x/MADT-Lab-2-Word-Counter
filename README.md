When the app starts:

    Find my input box.
    Find my dropdown.
    Find my button.
    Find my result area.

    Create my TextCounter.

    Put these choices in the dropdown:
        Sentences
        Words
        Characters
        Numbers

When the button is clicked:

    Get the text.

    If there is no text:
        Show Toast.
        Stop.

    Find out what the user selected.

    If they selected Sentences:
        Ask TextCounter to count sentences.

    If they selected Words:
        Ask TextCounter to count words.

    If they selected Characters:
        Ask TextCounter to count characters.

    If they selected Numbers:
        Ask TextCounter to count numbers.

    Show the result.
